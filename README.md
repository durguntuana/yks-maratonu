## ✨ Özellikler

| Özellik | Açıklama |
|---------|----------|
| 📖 **Paragraf Maratonu** | 40 soruluk kronometreli paragraf denemesi, net ve puan hesaplama |
| 🧮 **Problem Maratonu** | 40 soruluk kronometreli problem denemesi, net ve puan hesaplama |
| 📊 **Çalışma Karnesi** | Günlük toplam çalışma süresi takibi, kronometre ve not defteri |
| 🎨 **6 Farklı Tema** | Yeşil, kırmızı, sarı, beyaz, siyah ve rengarenk tema seçenekleri |
| 🌙 **Karanlık/Aydınlık Mod** | Sistem ayarına göre otomatik gece/gündüz modu |
| 📱 **Mobil Uyumlu** | Telefon ve tablette sorunsuz kullanım |

## 🚀 Nasıl Kullanılır?

1. Ana sayfadan istediğin maratonu seç
2. Kronometreyi başlat ve soruları çözmeye başla
3. Doğru, yanlış, boş sayılarını ve süreni gir
4. "Günü Kaydet" butonuyla performansını takip et

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3 (özel tema sistemi, animasyonlar)
- JavaScript (localStorage veri depolama)
- Netlify (canlı yayın)
